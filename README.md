# ACM_01 — Separation of Responsibilities

Проект переработан по принципам лекции 11.

## Архитектура

- `ACM.BL` — бизнес-модель и бизнес-правила:
  - `Customer`
  - `Product`
  - `Order`
  - `OrderItem`
  - интерфейсы репозиториев как абстракции доступа к данным
- `ACM.DAL` — отдельный уровень доступа к данным:
  - `CustomerRepository`
  - `ProductRepository`
  - `OrderRepository`
  - `OrderItemRepository`
- `ACM.BLTest` — модульные тесты.

## Что изменено

Ранее сущности одновременно отвечали за состояние, валидацию и доступ к данным (`Retrieve`/`Save`).
Теперь:
- сущности содержат только данные и относящееся к предметной области поведение;
- `Retrieve`/`Save` вынесены в DAL;
- BL зависит от абстракций репозиториев, а не от конкретных классов DAL;
- конкретный DAL ссылается на BL;
- тесты используют интерфейсы репозиториев.

Репозитории пока содержат заглушки вместо реальной БД — это сохранено из исходного учебного проекта.
